# 发布验证

v1.2.0 已通过 18 项核心与窗体流程检查，并通过实际发布 EXE 的自动运行验证：从不同工作目录启动、默认黑名单定位、首次登记及回收、改名重复视频回收、首次时间保留和运行后目录结构。检查汇总为 `test-results.json` 和 `release-validation.json`，不含运行机器的路径。

发布前需要完成以下检查：

- 主程序编译成功，名称为“本地视频拉黑”，目标为 Windows x64 / .NET Framework 4.8。
- 核心及窗体流程测试通过；包括真实回收和大小/SHA256 校验。
- 解压 ZIP 后第一层只含 `本地视频拉黑.exe`、空白 `blacklist.txt` 和 `app` 文件夹。
- 从其他工作目录启动，默认黑名单仍是 EXE 旁的 `blacklist.txt`。
- 日志写入 `app/logs`，不会在第一层新增日志目录。
- 对公开的源码、编译产物和最终 ZIP 逐一检查，不包含个人路径、真实黑名单、历史日志或凭据。
- 验证 ZIP 内文件与 `app/checksums.json` 的 SHA256 相同。

测试通过实际 WinForms 拖放事件入口加入文件，并在原生窗体后台完成登记与回收；该测试不代表完成了资源管理器鼠标拖放的人工验收。

测试日志可能包含运行机器的测试路径，不随公开包分发。随包只提供不含机器路径的检查汇总。
