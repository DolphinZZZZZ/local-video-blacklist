# 本地视频拉黑

一个 Windows 本地视频黑名单工具。拖入视频，点击“拉黑并移入回收站”，先登记文件大小、SHA256、视频信息和时间，成功后将视频移入 Windows 回收站。

不需要安装，不需要管理员权限。主程序不联网、不扫描下载目录，不自动处理队列之外的文件。

## 下载与使用

从 [Releases](https://github.com/DolphinZZZZZ/local-video-blacklist/releases/latest) 下载 `local-video-blacklist-v1.2.0-win-x64.zip`，完整解压后双击 `本地视频拉黑.exe`。

```text
解压后的文件夹/
├── 本地视频拉黑.exe
├── blacklist.txt          # 初始为空，默认黑名单
└── app/
    ├── ffprobe.exe        # 本地视频信息探测
    ├── logs/              # 使用时生成的操作日志
    ├── checksums.json     # 发布文件校验
    └── project/           # 完整项目、文档、许可证及依赖源码
```

请保留整个文件夹，`app` 是运行必需的部分。放在当前用户可写入的目录中使用，避免放进系统受保护目录。

1. 打开主程序，默认黑名单始终位于 EXE 同目录，文件名是 `blacklist.txt`，与启动时的工作目录无关。
2. 拖入一个或多个视频，或者点击“添加视频…”。拖入只加入队列。
3. 点击“拉黑并移入回收站”。登记成功后才回收视频。
4. 查看每项处理结果；“查看运行日志”打开 `app/logs`。

“移出队列”和“清空队列”只影响列表。点击“停止”会停止后续任务；当前已经登记的视频会继续完成回收。需要恢复视频时，可在 Windows 回收站还原。

## 重复视频与时间

- **文件大小和 SHA256 都相同**：保留原登记及首次时间，仍将这次明确选中的视频移入回收站。改名或换目录不影响识别。
- **同名但内容不同**：追加新的指纹记录。
- **旧记录只有路径**：保留旧条目，另追加本次完整指纹。
- 新条目使用带毫秒和时区的北京时间（`+08:00`）。重复登记不更新时间。旧条目没有时间时不会用重试时间冒充历史时间。

这套规则识别完全一致的文件内容；转码、裁剪或重新封装通常会改变 SHA256。

## 并发和数据保护

取得 Windows 文件写入句柄后，重新读取最新黑名单、去重、从末尾追加；整个过程都持有同一写入锁。其他写入者和文件替换操作会被阻止，最多等待 30 秒。写入刷新并读回成功后才允许回收。

登记失败不会回收；登记成功但回收失败时保留登记，重试不会重复追加。回收通过 Windows Shell 接口执行，拒绝永久删除模式，并核对原路径和回收站中的文件身份。

其他写入程序也应当在取得写锁后重读最新内容。编辑器在稍后保存很早读取的旧副本，仍可能覆盖新记录；文件锁不能阻止后续人工覆盖。强制结束进程或断电也可能留下未完成的尾行，需要检查。

支持 UTF-8、UTF-8 BOM、UTF-16 BOM，并保留原编码和已有字节。无 BOM 且不是合法 UTF-8 的文件会停止处理。仅支持本地固定磁盘和当前用户的回收站；不处理网络盘、移动盘、符号链接、目录联接和文件夹。

## 隐私与格式

发布的 `blacklist.txt` 为空，源码和发布包不含个人黑名单或历史操作记录。

程序使用后，黑名单及 `app/logs` 会包含用户选中视频的完整路径、内容指纹和操作时间，均保存在本地。分享文件夹前请自行移除这些个人数据。程序没有上传接口或遥测。

每条记录的格式为：

```text
视频完整路径 | size=字节数 | duration=秒数 | 宽x高 | 视频编码+音频编码 | sha256=64位指纹 | blacklisted_at=2024-01-02T03:04:05.006+08:00
```

`time_source`、`time_precision` 等历史来源字段可保留，不影响大小和 SHA256 匹配。每次操作的独立时间还会写入日志的 `TimeUtc` 字段。

## 构建

运行环境：Windows 10/11 x64，.NET Framework 4.8。主程序使用 Windows 自带的 C# 编译器，不依赖 NuGet 包。

源码仓库不提交生成的 EXE。发布 ZIP 已包含可运行程序及完整源码；直接使用请下载 Release。

从源码构建依赖时，在 Linux/WSL 安装 `make` 和 `gcc-mingw-w64-x86-64`，然后执行：

```bash
bash scripts/build-ffprobe.sh
```

在 Windows PowerShell 7 中构建主程序及测试：

```powershell
pwsh -NoProfile -File ./build.ps1 -BuildTests
```

也可以通过 `-ProbePath` 指定自行编译的兼容 ffprobe。构建结果位于 `build/本地视频拉黑`。构建脚本遇到已有输出目录会停止，请先移走旧构建。

生成完整便携 ZIP：

```powershell
pwsh -NoProfile -File ./scripts/package.ps1
```

包内 `app/project` 的源码也可以用相同方式构建，默认复用旁边的 `app/ffprobe.exe`。

## 验证

测试包含 12 个独立进程的并发追加/去重、编码保护、写锁超时及取消、失败重试、真实 ffprobe、真实回收站、窗体后台工作流程、时间保留和便携路径检查。测试只使用调用者提供的测试目录与合成视频；真实回收测试会将这些测试视频移入回收站。

```powershell
./build/tests/Tests.exe ./build/test-run ./tests/fixture.mp4 ./vendor/ffprobe.exe
```

`tests/fixture.mp4` 是随源码提供的 1.2 秒合成视频，不含个人媒体。`PortableSmoke.exe` 可对**空白发布副本**验证实际 EXE 的默认路径、两次回收、首次时间保留和运行后目录结构；它会更改该测试副本的黑名单，并回收测试目录中生成的两个视频。

发布验证的检查范围见 [docs/VALIDATION.md](docs/VALIDATION.md)。
